# 1️⃣ Python code mattum change panna (Most Common)

Example:

* `src/main.py`
* `models/*.py`
* `database/*.py`
* `telegram/*.py`

**Need build?** ❌ No

Just restart:

### GPU

```bash
docker compose down
docker compose up
```

### CPU

```bash
docker compose -f docker-compose.cpu.yml down
docker compose -f docker-compose.cpu.yml up
```

---

# 2️⃣ `requirements.txt` change panna

Example:

* New package install
* Package version change

**Need build?** ✅ Yes

### GPU

```bash
docker compose down
docker compose build
docker compose up
```

### CPU

```bash
docker compose -f docker-compose.cpu.yml down
docker compose -f docker-compose.cpu.yml build
docker compose -f docker-compose.cpu.yml up
```

---

# 3️⃣ Dockerfile change panna

# 📋 Quick Cheat Sheet

| Changed File         | Build Required? | Command                                                                       |
| -------------------- | --------------- | ----------------------------------------------------------------------------- |
| `*.py`               | ❌ No            | `docker compose down && docker compose up`                                    |
| `.env`               | ❌ No            | `docker compose down && docker compose up`                                    |
| `requirements.txt`   | ✅ Yes           | `docker compose down && docker compose build && docker compose up`            |
| `Dockerfile`         | ✅ Yes           | `docker compose down && docker compose build && docker compose up`            |
| `docker-compose.yml` | ❌ Usually No    | `docker compose down && docker compose up`                                    |
| Docker cache issue   | ✅ Clean Build   | `docker compose down && docker compose build --no-cache && docker compose up` |

This is the workflow I recommend for your project. Most days you'll only need a simple restart after changing Python code, and only rebuild when dependencies or the Docker image itself changes.




Assuming file name:

docker-compose.cpu.yml

Run:

docker compose -f docker-compose.cpu.yml up --build

Background-la:

docker compose -f docker-compose.cpu.yml up -d --build

Container-kulla poga:

docker compose -f docker-compose.cpu.yml exec frouros bash

Stop panna:

docker compose -f docker-compose.cpu.yml down
